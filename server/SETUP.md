# Запуск проверки ID — пошаговая инструкция

Займёт примерно 20–30 минут. Всё бесплатно.
**Токен бота никому не отправляйте, в том числе в чат с Claude.** Он вводится только в панели Cloudflare.

---

## Шаг 1. Создайте своего бота

1. Откройте в Telegram **@BotFather** и отправьте `/newbot`.
2. Придумайте имя, например `AVA TRADE Проверка`, и адрес, например `ava_trade_check_bot`.
3. BotFather пришлёт **токен** — длинную строку вида `123456:ABC...`. Сохраните его в заметках.

## Шаг 2. Сделайте бота администратором закрытого канала

1. Откройте канал → Управление каналом → **Администраторы** → Добавить администратора.
2. Найдите своего бота по адресу из шага 1.
3. Оставьте включённым право **«Пригласительные ссылки» / «Добавление участников»**. Остальные права можно выключить.

Без этого права бот не сможет создавать одноразовые ссылки. Тогда кнопка «Одобрить» честно покажет ошибку, и человек доступ не получит.

## Шаг 3. Узнайте ID канала

Откройте канал на **web.telegram.org** с компьютера. В адресной строке будет число вида `-1001234567890`. Это и есть ID канала.

## Шаг 4. Создайте сервер в Cloudflare

1. Зарегистрируйтесь на **dash.cloudflare.com**.
2. **Workers & Pages** → **Create** → **Create Worker** → назовите `ava-trade-verify` → **Deploy**.
3. Нажмите **Edit code**, удалите всё, вставьте содержимое файла `server/worker.js` → **Deploy**.
4. Запишите адрес сервера вида `https://ava-trade-verify.ВАШ-ЛОГИН.workers.dev`.

## Шаг 5. Создайте хранилище заявок

1. **Storage & Databases** → **KV** → **Create** → имя `AVA_KV`.
2. Вернитесь в ваш Worker → **Settings** → **Bindings** → **Add** → **KV namespace**.
3. Variable name: `AVA_KV`, хранилище: `AVA_KV` → **Save**.

## Шаг 6. Впишите секреты

Worker → **Settings** → **Variables and Secrets** → **Add**:

| Имя | Тип | Что вписать |
|---|---|---|
| `BOT_TOKEN` | Secret | токен из шага 1 |
| `WEBHOOK_SECRET` | Secret | любая длинная случайная строка из латинских букв и цифр, например 40 символов |
| `CHANNEL_ID` | Text | ID канала из шага 3 |
| `ALLOWED_ORIGIN` | Text | адрес вашего сайта, например `https://vadim626.github.io` |
| `ADMIN_CHAT_ID` | Text | ваш Telegram ID — узнаете в шаге 8 |

## Шаг 7. Соедините бота с сервером

Вставьте в адресную строку **своего** браузера, подставив свои значения:

```
https://api.telegram.org/botТОКЕН/setWebhook?url=https://АДРЕС-СЕРВЕРА/telegram/webhook&secret_token=WEBHOOK_SECRET
```

Должен появиться ответ `"ok":true`.

## Шаг 8. Узнайте свой Telegram ID

Напишите своему боту `/start`. Он ответит: «Ваш Telegram ID: 123456789».
Впишите это число в `ADMIN_CHAT_ID` из шага 6 и сохраните.

## Шаг 9. Подключите сайт

Пришлите Claude **только адрес сервера** из шага 4, без токена. Claude впишет его в сайт.

## Шаг 10. Проверка

1. Откройте сайт, введите любой тестовый ID.
2. Бот пришлёт вам заявку с кнопками ✅ / ❌.
3. Нажмите ✅, и на сайте появится кнопка «Вступить в VIP-канал».

---

### Как это работает каждый день

- Человек вводит ID → вам приходит сообщение от бота.
- Вы проверяете ID в PocketPartners Bot → нажимаете ✅ или ❌.
- При ✅ человек сразу видит на сайте кнопку входа. Ссылка одноразовая: вступить по ней сможет только он.
- Если ID уже подавали раньше, бот предупредит вас об этом в сообщении.
